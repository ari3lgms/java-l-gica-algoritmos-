# ☕ Exercícios e Algoritmos em Java

Repositório contendo resoluções de problemas de lógica de programação e algoritmos desenvolvidos em Java.

## 📌 Conteúdo
1. **Controlo de Intervalos (`Questao 1.java`):** Manipulação de laços de repetição para exibição de intervalos abertos e fechados.
2. **Simulador de Eleição (`Questao2.java`):** Processamento de votos de candidatos, nulos e brancos com cálculo percentual.
3. **Cálculo de Média de Idades (`Questao 3.java`):** Aplicação de laço pós-testado (`do-while`) para leitura de dados e processamento estatístico.

## 📂 Como Executar
Abra os ficheiros numa IDE Java (NetBeans, IntelliJ IDEA, Eclipse ou VS Code) e execute a classe `main` correspondente.
